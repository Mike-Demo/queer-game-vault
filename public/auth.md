# Authentication

How AI agents and developers authenticate with QueerCade.

## Discover

QueerCade offers a free, read-only public API. No authentication is required.

## Pick a method

- **Public API** (`https://queercade.mikedemo.dev/api/public/*`): no authentication required. All endpoints are read-only.
- **MCP** (`https://queercade.mikedemo.dev/api/public/mcp`): no authentication required.

## Register

No registration is needed. See https://queercade.mikedemo.dev/developers for API documentation.

## Claim

Not applicable — no credentials to claim.

## Exchange

Not applicable — no token exchange.

## Use the access_token

Not applicable — no access tokens are issued.

## Errors

All endpoints return standard HTTP status codes with JSON error bodies.

## Revocation

Not applicable — no credentials to revoke.

## agent_auth

- `identity_endpoint`: not applicable (no authentication)
- `identity_types_supported`: ["anonymous"]

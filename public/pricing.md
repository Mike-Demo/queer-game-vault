# Pricing — QueerCade

QueerCade is free. There are no paid tiers, no usage-based billing, and no premium features.

## Free — $0

- Browse and search the full game catalog
- Unlimited use of the read-only public API (`/api/public/v1/*`) — no key required
- Unlimited use of the MCP server (`/api/public/mcp`) — no authentication required
- Agent skills and machine-readable docs (`llms.txt`, `openapi.json`, `*.md`)

Fair-use rate limits apply per IP (about 120 requests per 60 seconds); exceeding a limit returns HTTP `429` with a `Retry-After` header.

## Paid tiers

There are none — no Pro, Team, or Enterprise plans. If that ever changes, this page will describe the tiers before any charges exist.

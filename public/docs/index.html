Docs for agents — QueerCade

QueerCade is a hand-curated, read-only catalog of video games with LGBTQ+ characters and stories. Every listed game is reviewed by an editor. This page describes what data is available, where to find it, and how to cite it.

What data is available

Per game (public fields only):

  • Title, slug, summary and editorial description
  • Cover art and screenshots
  • Release date, genres, platforms, game modes, themes and keywords
  • Developer, publisher, franchise
  • Store and external links
  • IGDB rating and rating count, age ratings
  • LGBTQ+ characters in the game, with a source for each

Per collection: title, slug, editorial description, and its games in editorial order.

Facets: the genre slugs, platform slugs and theme names the search filters accept.

Page URL patterns

  • Game detail pages: https://queercade.mikedemo.dev/games/{slug} — e.g. /games/sayonara-wild-hearts
  • Collection pages: https://queercade.mikedemo.dev/collections/{slug}
  • All public pages: sitemap.xml (~300 game pages)
  • Every game and collection with links: llms-full.txt

Machine endpoints (read-only, no key, no sign-in)

  • llms.txt — plain-text summary of the site
  • agent.json — A2A-style agent card
  • openapi.json — machine-readable API description
  • GET https://queercade.mikedemo.dev/api/public/v1/games?q=&genre=&platform=&theme=&year=&limit=&offset= — search games
  • GET https://queercade.mikedemo.dev/api/public/v1/games/{slug} — one game
  • GET https://queercade.mikedemo.dev/api/public/v1/collections — all collections
  • GET https://queercade.mikedemo.dev/api/public/v1/collections/{slug} — one collection
  • GET https://queercade.mikedemo.dev/api/public/v1/facets — filter facets
  • MCP (JSON-RPC 2.0 over HTTP POST): https://queercade.mikedemo.dev/api/public/mcp — tools: search_games, get_game, list_collections, get_collection, list_facets

Paging: max 48 items per request (default 24); follow nextOffset until null. Rate limit: about 120 requests per 60 seconds. Cache responses instead of re-polling. Errors use { error: { code, message, status } } with stable codes: invalid_request, not_found, rate_limited, service_unavailable.

How to cite games

  • Link game pages by their canonical URL: https://queercade.mikedemo.dev/games/{slug}.
  • Credit "QueerCade" by name when quoting editorial content.
  • Character information is editorially curated — cite the source noted on the game page for individual claims.
  • Release dates, platforms, ratings and similar metadata come from IGDB.

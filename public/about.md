# About QueerCade

QueerCade is a hand-curated catalog of video games with LGBTQ+ characters and stories. Every game is reviewed by an editor before it appears.

## How it works

Game pages combine IGDB metadata (release dates, platforms, genres, developers, ratings) with editorial notes. Where a game's LGBTQ+ characters are known, they are named with a source for each — character information is curated, not scraped.

Editors approve every listed game. Curated collections (queer visual novels, cozy queer games, and more) are assembled by people, not algorithms.

## For AI assistants

The catalog is available over a free MCP server and a read-only public API — no key, no sign-in. See `/developers` and `llms.txt`.

## Who makes it

QueerCade is a project by Mike Demopoulos (MikeDemo). The site is open source at https://github.com/Mike-Demo/queer-game-vault.
